## About

FIKRADO Security is a cybersecurity and technology education company focused on helping individuals, organizations, and communities build a safer digital future. The website presents FIKRADO's security services, AI and programming courses, technology books, educational videos, and company information in one professional, multilingual experience.

The site is available in English, Somali, and Amharic, making practical cybersecurity and technology knowledge more accessible across East Africa and beyond.

## Features

- Multi-page experience covering Home, About, Services, Courses, Books, Videos, and Contact
- Cybersecurity services and technology education presented in a clear, professional layout
- AI education and practical programming learning content
- Responsive design for desktop, tablet, and mobile screens
- Animated 3D scenes, cyber-grid backgrounds, particles, and polished motion effects
- Seamless infinite carousel showcasing organizations that trust FIKRADO
- Multilingual support with English, Somali, and Amharic language selection
- Automatic language detection with a manual language selector
- Mobile navigation menu and accessible interactive controls
- SEO metadata and deployment-ready static output

## Technology

- **React 19** — user interface and page composition
- **Vite** — fast development and production builds
- **React Router** — client-side page navigation
- **React Three Fiber** — interactive 3D scenes powered by Three.js
- **Framer Motion** — page transitions, animations, and micro-interactions
- **Lucide React** — consistent interface icons
- **CSS** — responsive layouts, visual effects, animations, and the FIKRADO design system

## Getting started

### Requirements

- Node.js 18 or newer
- npm

### Install and run

```bash
npm install
npm run dev
```

### Create a production build

```bash
npm run build
```

The production files are generated in `dist/`.

## Deploy to GitHub Pages

1. Push this repository to GitHub. The repository name should be `FIKRADO-Security` for the current base path, or update the base path in `vite.config.js`.
2. Open **Settings → Pages** in GitHub and choose **GitHub Actions** as the source.
3. The included workflow in `.github/workflows/deploy.yml` builds and deploys the site whenever changes are pushed to `main`.
